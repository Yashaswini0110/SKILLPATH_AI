# What-if career comparison (Phase 21)

Compare catalog roles against the **current** skill profile.

```text
Current skill profile
        ↓
Catalog role A / B / C
        ↓
Coverage, missing skills, estimated hours,
hypothetical path, projects, mentor overlap
```

The saved target role and stored learning path do not change.
GitHub evidence is not used.

This is **not** a hiring or employment prediction. It only reports
competency coverage and estimated learning effort.

`GET /api/v1/what-if?role_ids=` accepts one to four catalog role IDs.
